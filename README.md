# 史莱姆寓言 · Web 版（SlimeFable Web）

把「历史上的今天」做成史莱姆冒险：一个 Home 主关卡（凝露港），每天自动挂上当天可玩的年份关卡。
这是 UE 5.8 原项目 SlimeFable 的 Web 版，用来验证每日上新的玩法循环，并把迭代成本降下来。

## 运行
需要 Node.js 20.19+。

- 直接玩：先 `npm run build`，再双击 **Start.cmd**，浏览器打开 `http://127.0.0.1:5180`。
- 开发：`npm ci` → `npm run dev`
- 检查：`npm run check`（类型）· `npm test`（单元测试）· `npm run build`
- `?date=MMDD` 可以模拟任意日期，例如 `/?date=0815`

## 现在有什么
- **凝露港 Home 关**：从临水书埠出生，六扇时光门与史书台共用一座青石院落。沿水巷可到两座钓台，出院可去风车公园、镜湖、梯田和松果林。建筑与建造模式使用《林栖》自制模型。
- **每日匹配**：读取玩家本地日期；当天有内容就展出当天，没有就展出最近的历史档案，大厅不会空。史书里可以切换展出哪一天。
- **每日关卡**：各章的本地试玩入口、待制作关卡和当前返工见[项目进度与试玩目录](docs/progress.md)。
- **水面**：水巷与镜湖映出周围建筑和植被。史莱姆落水会漂浮，带水花、波纹和尾迹。雨来时石埠积水，雨后南边能看到彩虹。
- **时光碎片**：书埠、水巷和茶坡散落着 12 枚，收藏进度保存在本地。
- **家园建造**：按 V 打开素材库，可续铺石径、摆放景组、移动已有作物的农床，在本次建造中撤销或重做。
- **游戏 UI**：标题页、HUD、交互提示、暂停、史书（日历、纪念品、操作说明）、时光门卡片，风格是绘本史书。

## 碰撞方案（2.5D 高度场）
旧方案把 22.7 万个三角形交给模拟线程逐个查询，靠近物体时主线程和模拟线程都会掉帧。
现在加载时一次性烘焙成 **0.2 m 网格的高度场**（`src/slime/height-field.ts`）：

- 每格记录「从地面开始连续的实体」的顶面高度。中间空出超过 0.75 m 的部分（路灯臂、屋檐、树冠）视为悬空，可以从下面穿过。
- 水面区域从水下 1.3 m 起算，所以忽略海底，船体和消波块照样实心。
- 墙体判定：脚下一圈采样点中，只要有一格高出台阶高度 0.34 m 就算墙，按 X、Z 两个轴分开滑动。

实测（Chrome，桌面）单次查询：移动 0.45 µs，地面高度 0.1 µs，粒子投影 0.15 µs，镜头射线 1 µs。

## 目录
```
content/            每日章节数据（DayMeta / ChapterMeta）
src/slime/          史莱姆角色：PBF 软体、Marching Cubes、渲染、高度场碰撞
src/home/           凝露港：布局、时光门、史书台、碎片、水面效果、碰撞烘焙
src/game/           状态机、日历、存档、每日匹配
src/ui/             游戏 UI
src/world/linqi/    《林栖》自制区域布局与道路数据
src/zones/          水巷、钓点、活动园、梯田和林间生活玩法
scripts/serve.mjs   本地静态服务（含 QA 截图接口）
tests/              单元测试
```
