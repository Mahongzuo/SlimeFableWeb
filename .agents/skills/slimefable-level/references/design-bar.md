# 设计标准（Opus 审稿用的尺子）

## A. 体验结构（每关 5–10 分钟）
| 段落 | 目的 | 要求 |
|---|---|---|
| 开场 0–30 s | 进入那一天 | 出生点构图：地标在画面里；第一句介绍 ≤ 50 字，说清“几年几月几日、在哪、要发生什么” |
| 上手 | 学会这关的核心动作 | 在安全区域用一次核心能力（例如先贴一面矮墙） |
| 展开 | 用核心能力解决 2–3 个变化 | 每个变化都要比上一个多一点：更高、更快、要组合两种能力 |
| 高光 | 历史的那一刻 | 节奏变化（计时、镜头拉远、特效、横幅），玩家亲手触发 |
| 收尾 | 知道发生了什么 | outro 两三句话写清结果和意义；给纪念品 |

## B. 史莱姆能力（至少用 2 种，并且和历史有关）
- 贴墙爬、翻上墙顶、蹬墙跳 → 高处、塔、屋顶、船舷、天线
- 分身（G + 左键）压住远处的板 → 两人才能完成的操作：开闸、同时按开关
- 属性 1 水 / 2 风 / 3 火 / 4 雷 / 5 暗 / 6 物 → 例子：水浇灌，风吹雾或转动旋翼，火点灯，雷接电路
- 摊开（C）→ 钻低缝、潜行、在冰面上滑
- 游泳、弹跳、低重力 → 水域、太空

## C. 画面（详见 art-bible.md）
- 出生点、主路中段、高光点三个机位，每一张都要像一张“明信片”：前景、主体、背景三层分明。
- 年代特有的细节 ≥ 3 个，写在设计页里，搭建时逐一落实。
- 每 10 m² 至少 1 件生活痕迹；不用一个大盒子充当整面墙或整片地面。
- 引导靠灯光、颜色和地标：主路两侧亮一点，目标点有发光或飘动的东西，不靠箭头和文字。

## D. 复玩（至少 2 种，写进 save.data.life.records）
计时奖牌（金银铜的阈值写在关卡规格里）、全收集、限制条件通关（例如不用分身、只用一种属性）、隐藏纪念品、第二结局或彩蛋对话、每日种子变化（同一天的布局固定，换一天会变）。

## E. 自评表（交付前每项打 1–5 分，低于 4 分先改）
| 维度 | 5 分是什么样 |
|---|---|
| 辨识度 | 截图不带字，也能猜出是哪一年、哪个地方 |
| 细节密度 | 三个机位都没有空地和光秃秃的墙 |
| 高光时刻 | 玩家会想截图或录屏 |
| 能力运用 | 至少 2 种能力，并且和历史有关系 |
| 可读性 | 不看任务栏也知道往哪走 |
| 性能和体积 | 新增绘制调用 ≤ 150，压缩后 ≤ 60 KB |
