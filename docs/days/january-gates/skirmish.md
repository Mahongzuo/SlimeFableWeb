# 一月 · 五号门分身交火设计卡

每张卡以项目任务卡中的五门工作包为可改文件范围。日期为当地民用日期，另注 UTC 的以原始机构的 UTC 日为准。每关的地图、靶与回击、角色、道具和结尾均为互动演绎。全部由凝露港原生流体角色投射、收回分身，并用另一种身体能力取得角度。正式布局固定，随机练习只改变靶相位。收集按逐日故事保存，正式和练习记录各自独立。

### 0101 · 坦帕湾的第一班

- 事实（1 月 1 日）：1914 年，圣彼得堡至坦帕的定期客运航线开航。 [当日记录](https://airandspace.si.edu/stories/editorial/early-airlines-you-might-not-have-heard)
- 地图草图（从左向右）：`栈桥→浮台／船棚高廊→放行铃`。地标及制作细节：双翼水上飞机、浮筒、木肋船棚。
- 上手：从栈桥投一个分身打中风向靶，收回后试跳到浮台。 决策：近岸通道的浮标便于回收，高廊把三处移动风向靶纳入同一视线。
- 收束：激活最后一座放行铃，双翼机沿水面滑行、抬头离水。 纪念品「首航空邮签」。复玩：零次受击／走完两条分岔。

- 上手：用分身打亮第一道冰蓝颗粒，弹跳越过收拢的网框。 决策：搭外框打分散的稀尘靶，或在中央等高速密集尘束穿窗。
- 收束：手动合拢采样板，显示自己的颗粒轨迹。 纪念品「彗尘格窗」。复玩：填满外围网格／不遗漏主尘束。

- 收束：锁上坐标格，三次位置在灯箱连成短弧。 纪念品「星点刻度窗」。复玩：不碰干扰星／找齐三张叠片。

### 0108 · 旋臂上的灯
