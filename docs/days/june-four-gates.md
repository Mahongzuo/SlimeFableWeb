# 六月四扇门 · 逐关事实与设计

每天三件中国史事、一件海外史事。3、4、5、6 号门依次为塔防、三消、分身交火和战斗 RPG。左侧两篇历史章节沿用原入口。每行的史料记录实际事件，路线、标记、机关、训练偶和纪念品均为游戏演绎。人物诞辰关以其专业为布景。

塔防分三段迁塔守六波，三消分三幕且可加演，分身交火需走过两道并点亮四靶，RPG 从两条能力路线择一挑战训练偶。正式与随机练习分账。
