## 中段读法与失误补救

| 日期 | 玩家可以观察到的信号 | 可以怎样补做 |
|---|---|---|
| 12/12 | 接收棚的指针扫过铜线时，灯与短音一起提示电键时机。气候图先拼哪一页，决定余下两枚图例的颜色。 | 系好风筝天线后落地调谐。漏按一个点就等下一次闪光，纸带会保留前面的点。 |
| 12/13 | 护烛时火苗会安定，托起的纸鹤会随角色移动。路标旁的风带有起落，近旁还有可随时投递的背风位置。 | 纪念庭可以原地慢慢继续。摇筛时若样格未亮，重走“中央金线、篮边、中央金线”这一小段即可。 |
| 12/14 | 桩脚上的竖纹与堤身横纹指示两次清除的方向。光学台可以沿灯箱、窄缝、棱镜看到彩光的去向。 | 回到光谱台当前发光按钮，每份能量松手再按一次，补齐格数后再送到对端。 |
| 12/15 | 月车相机先留一张底片，再用另一团反光回拍。展柜双壳到位后，中缝是最后一个支撑点。 | 合壳后揭幕扣没亮时，把本体移到中缝。金星纸带漏过波峰可等下一次，或在慢录路线摊开稳住。 |
| 12/16 | 洞口纵纹和桥口横纹通向不同进站线。书斋地球仪上的金环标出每个覆盖扇面的弧顶。 | 走直线留下缺口时，从弧顶光圈接着走到对侧，再合拢这一扇。 |

每个页面的 **F1 帮助**会读出当前目标。竖屏还会显示本门的触屏操作，完整走法由玩家自行展开。纪念庭不设计时或收集要求。其他采用星尘收藏规则的章节可先完成主机关，想带回原纪念品需在收尾前收齐八颗星尘。
