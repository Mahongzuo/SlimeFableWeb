# 11/16 设计页

## 1116-1974 · 给宇宙发一张像素画　〔模板：landmark（新）〕
### 事实卡
- 1974-11-16，在波多黎各的阿雷西博射电望远镜改造落成典礼上，向球状星团 M13 发出了一段由 1679 个二进制位组成的无线电信息。按 23 列、73 行排列，可以拼出数字、DNA、人形、太阳系和望远镜本身的图案。
- 来源：https://en.wikipedia.org/wiki/Arecibo_message
### 一句话体验
史莱姆沿着缆索和铁塔爬上悬在 150 米高空的接收平台，然后亲手“点亮”那张像素画，让信息飞向两万五千光年外的星团。
### 核心玩法（landmark 模板）
1. **攀爬**：一座巨型地标，由三根混凝土塔、缆索和悬挂平台组成。用到贴墙、蹬墙跳、沿缆索滑行；滑行是新动作，在缆索上摊开就能顺着坡滑下去。下方是喀斯特山谷里的巨大天线碗。
2. **点亮**：平台上有一面 23×73 的发光像素墙，太大的话可以分成 5 块，每块对应信息的一个部分。玩家拿着雷属性走过像素格就把它点亮。
   - 每一块都有“答案轮廓”提示，是半透明的。
   - 5 个部分：数字 1–10、DNA 双螺旋、人形、太阳系、望远镜。
3. **发射**：5 块全部点亮后，按下发射钮。
### 高光时刻
发射：天线碗中央亮起，一道光柱射向夜空，像素画化成一串光点飞向星空。镜头跟着光点飞出去，回头看见发光的地球；横幅写着“25,000 年后到达 M13”。
### 年代细节（≥3）
- 碗面和喀斯特山丘。
- 典礼的白色帐篷、乐队和观众。
- 1974 年的控制室：磁带机、行式打印机打出来的 0/1 纸带。
- 热带植物。
- 用现有的小动物系统做科奎蛙，夜里会叫（只做发光的小点，不要音频）。
### 复玩
- 攀爬计时奖牌。
- 一次画对、不涂错格子的挑战。
- 隐藏纪念品：打印纸带的一截，藏在塔顶。
### 模板 / 套件
新模板 `landmark`：一座大地标的攀爬路线加一个顶部谜题，路线和谜题都是数据。以后灯塔、自由女神像、埃菲尔铁塔之类的关卡都能复用。新套件 `arecibo-1974`。像素画谜题写成可复用的 `pixel-board` 模块。
### 机位
出生点在山谷底部，仰望悬挂平台；中段在缆索上，俯瞰天线碗；高光时光柱冲天。
