# 十二月二日至六日 · 六门技术验收

[五日制作页](../../docs/days/1202-1206-six.md) · [优化台账](../../docs/six-gate-polish.md)

逐日拼图从左至右为一到六号门。每门的原尺寸证据以 `dec-six-MMDD-门类` 命名，包含常规、贴地、远景、竖屏和结尾五张 JPG；同名前缀的 `result.json` 记录正式与练习结果。港口记录分别检查六个实体门和史书的“前往”按钮，核对返回后的日期和门位。浏览器使用独立无头 Chrome，开页前禁用指针锁。

## 实测覆盖

| 项目 | 结果 |
|---|---|
| 正式与练习 | 30 个正式结局和 30 个练习结局均可从入口完成。复玩成绩分别存放，旧收藏保留。首胜贝壳沿用北京时间当天、每个门位一次的规则。 |
| 入口和旧档 | 五个日期的章节 ID、固定门故事 ID、存档键、门位和试玩路径均与原登记一致。30 关分别从实体门和史书进入，60 次返回均落在原门前约 2.3 个世界单位处。 |
| 种子 | 每关测试 40 个种子。三消使用相邻交换推进，塔防让目标实际通过控制区，六号门的两种能力均逐段操作。 |
| 章节收藏 | 五个首章各自保留 8、4、5、6、6 枚藏签；五个次章分别实测收齐八颗星尘后取得纪念品。留声机记录和重放玩家实际走出的音高顺序。 |
| 角色与重试 | 六类玩法均使用凝露港流体角色。头两门和五号门检查位移、分身、形变或跌落恢复；塔防和三消实测失守／耗步后的重试；六号门在第二段故意耗尽体力，再从本段完成。 |
| 布景与画幅 | 30 份逐门记录、150 张原尺寸实机图。六号门按手机竖屏验证触点对应的地面移动，五号门用触屏投出最后一团分身。铁路洞门另测了中心射线和 13 处拱券接缝。 |


## 项目检查

- `npm run check`、`npm run build` 与项目内容检查通过。
- `npm test` 通过 1,681 项，失败和跳过均为 0。六号门另复测了来回蹭棘齿不会收满吊绳、直接跳到纬带终点不会显影。
- `npm run catalog` 后通过 `npm run catalog:check`。目录涵盖 366 天、740 个可玩章节与 1,471 个固定模式挑战。
- 150 张逐门截图均可读取，文件内容互不重复。每个日期另存一张六门拼图，30 份成绩记录包含正式与练习结果。
