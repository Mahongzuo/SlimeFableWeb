## 史料与游戏演绎

逐日比对日期、年份、事件和第一关。新关含 91 条 NASA 食象、49 条 F1 官方赛果、28 条 MoMA 藏品入藏记录、25 条纽约爱乐节目、79 条历史日历人物记录。音乐会对应节目编号，艺术品按入藏日期登记。凤凰号的发射日期另查 [NASA](https://science.nasa.gov/mission/mars-phoenix/)，和平纪念关的开馆日期另查[纪念馆馆史](https://www.19371213.com.cn/about/history/)。玩家操作的灯座、压桥、比赛与舞台等机关均为游戏创作。[逐日设计和原始链接](../../docs/days/second-calendar.md)

## 玩法与技术验证

- 每月都有分身投射与回收、双元素导通、木靶连击、攀壁、浮游和双分身协作。原版流体角色在单独的物理工作线程中运算；压力板读取落地分身的位置，连击读取木靶实际受击，水路读取角色所在水体和当前属性。
- **274/274 个新增章节通过逐关浏览器验证，待跑 0 个。** [浏览器逐关结果](1122-second-calendar-results.json) 列出通过的稳定 ID、主机制及其反例。批量回归发送游戏输入，读取机关状态、通关和纪念品存档，再点击回港并核对日期。批量回归关闭 GPU 光栅化以缩短测试，代表性画面另在真实渲染模式截取。港口端到端检查用传送把角色放在门前，门的弹窗与实际页面跳转均走玩家入口。
- 单元测试涵盖所有新增章节的负例和正例，检查每月六种机制，读取旧版 370 个 ID 的模拟存档，完成新章后再读回旧记录。总计 361 项通过。类型检查、生产构建、总表检查及内容检查通过。
- 实测 0804-2007、0815-1985、0103-1904、0105-1954 在开场视角的完整单帧绘制调用分别为 67、101、69、97。复玩可挑战个人最快用时或零次无效校验，各自写入该关的记录。
- 画面及手感留给用户试玩确认。近战组共用幻想木靶，历史人物与纪念关使用非战斗叙事；其它日子的玩法由六种共同机制和各题材的场景生成。

## 复验

安装了 Python Playwright 和 Chrome 的工作机可运行下列命令。样例和批量检查使用独立的临时浏览器配置。

```powershell
npm run check
npm test
npm run build
npm run catalog:check
node .agents/skills/slimefable-level/scripts/lint-content.mjs
python scripts/qa-ability.py --vertical 0804-2007
python scripts/qa-ability.py --evidence 0815-1985
python scripts/qa-ability.py --jobs 2 --report tasks/reports/1122-second-calendar-results.json
```
