## 素材与复用

入口改为项目自己的 Three.js 家园渲染器。河谷地形、天空、雨丝、彩虹和湿石反光在新地图上生成。旧 SunHarbor 原始包、汉化包及其制作脚本均留在 GitHub 备份标签。新版源码树已移除这些文件。独立 Chrome 会话核对了家园与六次进出关卡的请求，均来自本机，生产目录不含旧港脚本。

素材库内 35 个 GLB、35 张配套缩略图逐文件与 DreamWorld 本地源文件比对，70 个均一致。建筑、植被、水岸物件和动物可追溯到 DreamWorld 的 `scripts/*pack.py` 建模源文件。区域布局、村落配置和道路覆盖共三个 JS 文件直接复用。主页与建造预览使用相同 GLB 和尺寸定义。本项目仍使用受许可的 Three.js 引擎与随引擎提供的加载和渲染组件。

## 建造与存档

按 V 进入建造，可摆放、移动、旋转、缩放、拆除、铺设三种地面、整组预览景组并扩建。一次会话可撤销和重做最近 40 次编辑。景组按成交价分摊拆除退款。旧档首次打开时，对重建河谷内的旧物件重算落点，必要时向附近可建岸地移动，保留原 ID、作物和设施记录。其他区域已有摆设保留原坐标。

## 技术验收

- 使用独立无头 Chrome，中档画质、1200 × 780、预先禁用指针锁。对照晴天、雨天、彩虹、俯视和岸路两个低机位时固定天气阶段。另存各分区和真实游玩视角。两版使用不同端口存档。[旧版晴天](../../qa/evidence/jiangnan-before-clear.jpg) · [新版晴天](../../qa/evidence/jiangnan-pilot-clear.jpg) · [雨景](../../qa/evidence/jiangnan-pilot-rain.jpg) · [彩虹](../../qa/evidence/jiangnan-pilot-rainbow.jpg) · [玩家视角](../../qa/evidence/jiangnan-pilot-play.jpg)
- 使用实际角色移动与碰撞，从出生点分别步行到六个门前，按 F、点击出发、加载每日关卡，再经关卡 UI 回家。十月十五日六个落点均在对应门前 2.3 米。摊开动作使用 C 键，实际求解器反馈 384 个粒子，表面顶点 5460 个。
- 五个钓点逐个触发甩竿、显示等鱼提示并收竿。九个梯田农床均登记到种植系统。铺设三种地面，摆亭，移动带作物的农床、拆除后撤销，景组整组落地与原地拒绝，存档重进及窄屏抽屉均通过。实测江南主题扩建 `tile_1_0` 及撤销、重做。[建造画面](../../qa/evidence/jiangnan-pilot-build.jpg)
- 岸路接面两侧的向下射线分别只命中一块铺地，接边七对顶点最大间隙约 9.8e-10 米。常规、贴地斜视与俯瞰机位均留档。[接缝正侧](../../qa/evidence/jiangnan-pilot-seam.jpg) · [接缝反侧](../../qa/evidence/jiangnan-pilot-seam-side.jpg) · [远景](../../qa/evidence/jiangnan-pilot-overlook.jpg)
- 同机固定机位，三组各十帧，每帧回读一个像素完成 GPU 同步。中位帧时旧版为 12.14 ms，新版为 5.11 ms。该项为短时场景对照。浏览器运行记录未发现脚本或着色器错误。[新版测试数据](../../qa/evidence/jiangnan-pilot.json) · [旧版测试数据](../../qa/evidence/jiangnan-before.json)

- 实际载入旧版格式的家园存档，原来位于河床的农床已移到岸上，同一农床 ID、作物、收藏和 57 枚贝壳均保留。另对天气控制器自然时间取样，12 秒晴朗、64 秒降雨、98 秒可见彩虹、312 秒进入暮夜。
- `npm run check`、`npm test`（1,520 项全部通过）、`npm run build` 已通过。Vite 仍提示部分公用分包超过 500 kB。

视觉和手感由玩家试玩确认，重点是出生第一眼、各区辨识度、雨后光色与建造物融合程度。
