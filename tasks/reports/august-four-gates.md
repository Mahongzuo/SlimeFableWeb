## 构建与取景

包含一至八月数据的共享构建已通过 `npm run check`、`npm test`、`npm run build`、`npm run catalog`、`npm run catalog:check` 及内容检查。整库测试 1,207 项全部通过，失败、跳过均为零。目录登记 644 个 Web 章节、986 项固定模式挑战。隔离浏览器测试使用的五个八月资源文件与 5180、5190 本机预览构建中的文件一致。

八月史事包 `august-pilots-ChKTeqrg.js` 压缩后 22.84 kB，四种玩法的八月配置分别为 2.23–3.08 kB。抽样塔防正式关额外绘制 72 次，三消 20 次，RPG 52 次。塔防宽屏的常规机位 (2.7, 12.5, 18)、低位 (7, 5.4, 18) 和远景 (2.7, 18, 21) 均朝向 (0, 0.55, -0.65)，可重点比较会车点和塔座外沿。

本次沿用四套程序化场景与原生角色。各日的路线、目标、棋面或试炼节奏按题材配置，同类场景共享部分地标轮廓。抽样技术自评为辨识度 4/5、细节密度 4/5、高光时刻 4/5、能力运用 4/5、可读性 4/5、性能和体积 5/5。实际设备上的画面、难度与操作手感待用户试玩确认。
