## 风帆之间

从本船海图桌接令。首敌倒下后，蓝旗船驶近；沿右舷梯道登艉楼，在绞盘旁转动望远镜。辨认半面蓝旗后放桥。上路有帆布射手与开阔射窗，下路穿过货舱，先遇到跃过缆箱的索具偶兵。两条路均能到达记录室。领航员铺位的日志会打开中层捷径。

带走图匣时，船首像守卫封住跨船通道。它的三发扇形凝露弹共享一次伤害判定，发射后帆结打开，可以抢一轮反击。守卫倒下后通过跳板或捷径返回海图桌，把两片残页接到对应的墨记旁。两列航迹最后分别写上纳尔逊和科林伍德的名字。

| 实走路线 | 已验证的结果 |
|---|---|
| 艉楼上路、跳过日志、原路返回 | 认错船停在绞盘，镜头中心实际看见蓝旗才选对。纯分身击败射手和守卫。第一片残页拼好时仍在任务中，第二片拼好后记录一次胜利，回到第五门外。 |
| 货舱下路、阅读日志、从捷径返回 | 对索具偶兵使用真实弹道和回收。拿图后主动受击倒地，恢复图匣、日志和检查点生命，突破守卫后走中层舱门。 |

## 关原雾阵

雾口用单旗横扫和拔旗收招带出第一次反击。分岔山道可走低路引开轻兵，也可从坡上先打护旗手。接近时，青色旗线显示庇护关系。两敌倒下后，回复 30 点生命或选择余程增伤 20%。守将半血展开背旗，部分横扫会接一次独立预告的回身击。守将倒下后，坡上的旗帜才变向，史书接回小早川秀秋转向东军的经过。

| 实走路线 | 已验证的结果 |
|---|---|
| 低路、普通连击、回复生命 | 实际受击后再补血，观察守将半血后的回身击，随后完成连击、收藏与回港。 |
| 高路、元素技能、余程增伤 | 走过 1.8 米高差，先打护旗手。守将前故意败北，检查点恢复生命、未使用的资源、守将与强化。先附着再在长收招时用物理 E 触发破韧，能让守将跪地。 |
| 混战索敌 | Tab 锁定，T 与触屏切敌可在可见目标间切换，右键侧闪后施法仍朝目标。岩障遮挡与超距时，硬锁定向技能保留能量和冷却。排队的连击逐击转向，敌人倒下后解除硬锁。船上保持手动瞄准。 |

## 验收和后续试玩

两个原有入口、纪念品 ID 与门位沿用。旧单敌试玩最快时间保存在原来的 `-ms`，完整任务使用 `-campaign-v1-ms`。正式与带种子的练习分别记次数及最快成绩。战区检查点用于同局失败重试。史实沿用出发页与史书中的核实来源，记录船、机关与旗甲敌人是游戏演绎。

生产包已在 5180 和 5190 核对，独立无头 Chromium 进行任务、存档与回港测试。运行 `npm run check`、`npm test`、`npm run build`、`npm run catalog:check` 和内容检查均通过，444 项测试通过。复测两条任务可运行 `python scripts/qa-battle-preview.py --base http://127.0.0.1:5190`。索敌、右键闪避及史料界面专项分别见 `scripts/qa-battle-lock-live.py`、`scripts/qa-battle-dodge.py` 和 `scripts/qa-battle-history.py`。

射击正式版的自动化路线耗时约 56 秒与 76 秒。驱动预先知道路线和交互点，直接计算瞄准角度，并持续冲刺；下路耗时包含一次刻意败北。8–12 分钟的首次游玩目标仍待真人验证。观察重点是首次认出蓝旗的时间、是否能自行发现铺位捷径，以及玩家能否从守将的身体动作预判第二击。
