# 六月四扇门技术验收

6 月 1–30 日每天开放 3 号塔防、4 号三消、5 号分身交火和 6 号战斗 RPG。每天四件独立史事，三件中国、一件海外。全月合计 90 件中国史事、30 件海外史事。原有 60 个六月历史章节与这批挑战分别登记。[逐日事实、来源、操作、纪念品和试玩](../../docs/days/june-four-gates.md)

## 制作范围

四种模式沿用项目已有的玩法和程序化场景。各日塔防配置路线、迁塔位置与收尾目标，三消配置三幕棋面、目标格或压印方向，分身交火配置双路目标的高度与顺序，RPG 配置试炼场、两条路线与收尾演出。120 件纪念品各自入册，按史事生成存档键。

## 构建与取景

`npm run check`、`npm test`、`npm run build`、`npm run catalog`、`npm run catalog:check` 和 `node .agents/skills/slimefable-level/scripts/lint-content.mjs` 全部通过。包含五月和六月的整库回归通过 1,019 项，失败、跳过均为零。目录共 366 天、644 个 Web 章节、739 个固定模式挑战。

浏览器记录对应六月史事资源 `june-pilots-BW-V-GLM.js`，gzip 后 22.34 kB。四种六月玩法配置各为 2.30–3.03 kB。六月的五个资源文件与最终本机预览构建逐一校验，哈希一致。塔防和 RPG 样本分别增加 71 和 52 次绘制调用。

塔防横屏可从常规机位 (2.7, 12.5, 18)、低位 (7, 5.4, 18) 和远景 (2.7, 18, 21) 看向 (0, 0.55, -0.65)，窄屏由程序拉远。可对照水位尺附近的塔座交界、布防位置和收尾亮灯。[竖屏截图](../../qa/evidence/june-0601-defense-portrait.jpg)

按项目六项标准对抽样关技术自评，辨识度 4/5、细节密度 4/5、高光时刻 4/5、能力运用 4/5、可读性 4/5、性能和体积 5/5。同主题日期共享部分场景轮廓和操作节奏；画面辨识度、实际设备表现和操作手感留给用户试玩确认。
