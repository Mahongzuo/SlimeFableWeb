# 风车公园：精细化（对齐凝露港的细节密度）

先读 `docs/art/zone-style.md`（美术规范）和 `src/zones/kit.ts`（已有的树、草、风摆工具），然后只改 `src/zones/park.ts`。

目标：玩家站在风车公园的任何位置环顾四周，细节密度都接近港口。要有远中近三层，有生活痕迹，风格是中式浙闽渔村。

本卡要加 / 改的内容：
风车加木平台和栏杆、磨坊门，塔身石块错缝；游乐场地面铺塑胶垫（不同色块拼接）；长椅有扶手、旁边放垃圾桶和饮水台；路灯底座加垫石；土丘上加一条石阶小路通往风车；草坪上放野餐垫和竹篮、风筝摊（写“风筝 5元”）、冰糖葫芦小推车（名字带 fx 的糖葫芦串）。

通用要求：
- 保留文件里现有的导出、玩法调用、交互点 id 和坐标。
- 新增物件尽量用 InstancedMesh，整个文件的 draw call 控制在 80 以内。
- 可穿过的物件按规范命名，可攀爬的结构要有厚度。
- 不许改其他文件，不许加贴图文件或依赖，不许出现日文或旗帜。

验收：`npm run check`、`npm test` 通过。Opus 会把截图和港口并排对比。
