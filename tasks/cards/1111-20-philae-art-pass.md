# 菲莱关美术返工（Opus 审稿意见）

附图中前 3 张是你上一轮做的 1112 · 2014 菲莱关，分别是三个机位：opening、cliff、finale。后 2 张是我们的质量基准：凝露港的湖和民居。现在差距很大，玩法逻辑基本可以保留，**画面要重做**。先读 `.agents/skills/slimefable-level/references/art-bible.md` 和 `docs/days/1112.md`。

## 问题和改法
1. **地形是一块方形石板，边缘锋利，悬在太空里。**
   - 彗星表面要是不规则的：用多层噪声的高度场，挖出坑（碗形，坑沿隆起），做出起伏的山脊。地面一直延伸到视野尽头，远处用曲率往下弯，看起来像在一个小天体上。
   - 任何机位都看不到地形的边界。
   - 颜色用深炭灰，上面有浅灰色的尘土斑块。
2. **平台是方盒子，顶面平涂一个色块。**
   - 改成岩石：用多个十二面体或二十面体堆叠，加上有分层的冰崖。冰崖侧面要有水平的岩层条带，背光面用冰蓝色高光。
   - 阳光平台的标志：一束斜射的光柱（半透明的锥形，名字带 fx），台面上有一圈细细的发光圈。不要大面积平涂色块。
   - 标签牌只保留着陆点名字（Agilkia、Abydos），做成小型的立牌。
3. **喷流做成了一簇实心尖锥，像水晶。**
   - 改成柔和的气体尘埃喷流：从彗星“地平线”边缘喷出，用多层半透明的长条加上缓慢上升的粒子（glowSprite 一类），带透明度渐变。
   - 喷流离玩家要远，作为远景。
4. **认不出这是一颗双瓣彗星。**
   - 玩家在其中一瓣上，另一瓣作为巨大的天体从地平线上升起，至少要占出生点画面的 1/3。
   - 外形是“鸭头”：一个凹凸不平的大球体，带坑和阴影。
5. **罗塞塔号太小、在画面边缘。**
   - 出生点要能清楚看到它：一个盒形本体加两块很长的蓝色太阳能翼，再加一个高增益天线碟。用 space 套件里的函数做，尺寸放大，放在天空中显眼的位置。
6. **finale 机位被一个大盒子挡住了。**
   - 调整机位，或者把挡住视线的几何体挪开。
   - Abydos 要在悬崖的阴影里，能看到悬崖的轮廓，头顶有罗塞塔号飞过，并有光柱。
7. **光照。**
   - 只用一个强烈的太阳光，阴影要深。
   - 星空更亮、更有层次，有不同的大小和亮度，再加一条淡淡的银河带。
   - 主题的 look 调高对比度。
8. 确认史莱姆身上挂着菲莱号的外壳：金色箔片的盒体、三条腿、天线。如果还没有就加上。
