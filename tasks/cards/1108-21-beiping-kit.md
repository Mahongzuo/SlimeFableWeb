# 主题套件：北平 1949（跑酷关 1001 · 1949《奔向天安门》）

先读 `docs/art/zone-style.md`、`src/templates/runner.ts`（`Piece` 的种类和含义），以及现在的 `src/themes/beiping.ts`。只改 `src/themes/beiping.ts`。

目标：一眼看出是 1949 年秋天的北平。灰砖胡同、四合院屋顶、宽阔的长安街、汉白玉金水桥、红墙黄瓦的城楼。细节密度要接近凝露港。

做法：保留导出 `beipingKit` 和 `RunnerKit` 接口，按 `piece.kind` 把现在的简单盒子换成更好的造型。外形必须仍然覆盖原来盒子的范围，因为碰撞是从你建出来的网格烘焙的：
- **wall / gate**：
  - 灰砖墙要有砖缝。墙头用筒瓦压顶。
  - gate 做成如意门或广亮大门：红漆门、门墩石、门簪、门楣，门两侧贴春联。
  - 墙根加青苔色带、晾衣竹竿、煤球堆、自行车等生活痕迹，这些名字带 fx。
- **crate / cart**：
  - 木板条箱，带麻绳。
  - 人力板车，木轮有辐条。
- **house / roof / ridge**：
  - 四合院倒座房：前檐柱、木格窗。
  - 屋面是合瓦垄，带屋脊、脊兽小件和檐口滴水。
  - 屋面可以走，屋面盒子的顶面高度不能变。
- **stair**：砖砌台阶或木梯。
- **avenue**（ground、crowd、lamp）：
  - 路面是浅灰沥青，加两侧人行道、电车轨道和架空线（fx）。
  - crowd 改成穿 1949 年服装的人群：中山装、学生装、长衫，部分人手里拿小红旗。人要分散站，碰撞范围不超出原盒子。
  - lamp 做成老式路灯，红灯笼可选。
- **bridge / rail / plinth / pole**：
  - 汉白玉桥面是微拱的视觉造型，但走的那一面要保持平。
  - 栏杆有望柱头。
  - 旗台做成汉白玉须弥座；旗杆是金属的，杆顶有球。
- **tower（天安门城楼）**：
  - 红墙、五个券门。
  - 汉白玉城台。
  - 重檐黄琉璃瓦，带檐角起翘。
  - 城楼正中挂毛主席像的位置只画一个金色方框，不要画人像。
  - 两侧挂红灯笼，城台上方挂“中华人民共和国万岁”“世界人民大团结万岁”两条横幅，用 canvas 中文。
- **water**：护城河水面的颜色要深一点。
- 天空颜色、雾、光照（`look`）可以调成秋日下午的暖光。

不许做：
- 改其他文件。
- 改任何会被站上去的面（ground、roof、stair、bridge、plinth）的顶面高度。
- 让可走路线上多出障碍。
- 加贴图文件或依赖。
- 出现日文。
- 画领导人肖像。
