# 临水书埠与可建岸路样板
1. 从 GitHub 已验证的备份制作旧版对照。在相同天气、画质、机位下记录旧版和新版。任务卡授权 game.ts 的建造 UI 接线与样板场景集成。
2. 石埠、六门、木亭、疏柳、水阶与公园岸路。沿用现有天空、水面、天气与阴影。
3. 用同一套模型预览和摆放，加入可折叠素材库、编辑、景组预览、铺地与独立旧档兼容数据。覆盖撤销、重做、农床作物与贝壳。
4. 独立无头浏览器禁用指针锁，记录出生点、接缝双角度、可建岸路与六门往返。三项项目检查全通过。视觉及手感由用户试玩。用户定稿后另立全港推广任务卡。
