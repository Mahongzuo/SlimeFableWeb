# 凝露港建筑免费素材升级

用可免费随游戏发布的建筑模型或构件改进港口、湖区、公园、农场和林区的建筑外观。13 种建筑目录模型与同名原生景观、建造预览及缩略图使用同版资源。保留旧档建筑 ID 和交互。以原有可通行空间、门洞、桥板、屋顶、轮轴和地基为对齐依据；独立地标用对应构件或材质，避免重复外壳。

记录实际作者、来源、许可与修改。本地部署优化后的资产。独立无头浏览器禁用指针锁，检查常规、贴地、远景和运动部件、旋转摆放、开放空间及同机位对比。类型、全量测试和生产构建通过，画面由玩家试玩确认。
